Four-effect design, preserving those artworks:
? : orb texture refraction inside ellipse only (implemented prototype here).
×2: use original tilted elliptical accretion texture; mask annulus excludes black
center and outer stars/clouds; tangent-aligned small flow, not a new spiral stroke.
MAX: mask crown gold face with original highlights/luminance and its actual contour;
slow specular travel over metallic facet. Cat, eyes, whiskers, ears stay fixed. No
sweat, droplets, floating diamond or extra ornaments, explicitly prohibited.
Reset: mask the actual filled arrow silhouette using contour + original cyan/white
pixels; specular intensity travels along the arrow surface. Not a rotating new icon,
not new circular strokes, not moving the entire original illustration.

? implementation: React Bits RippleDistortion's public waveFragment Gaussian/cosine
brush + composite image displacement adapted to plain WebGL, fused into ONE pass
(no displacement render target needed for the single finite wave). One renderer,
one canvas, one original texture per manager. Canvas moves to activated visible card.
At a time only one host, duration 1200ms, 30fps cap, DPR<=1.5, displacement <=.01UV.
Fixed mask center (.51,.66), radii (.29,.205), fading normalized radius .70–.88.
Outside mask alpha is zero, so image/frame/number remain the actual unchanged DOM.
No tint, grayscale, chromatic spread, added dot/line/shape, or particle cloud.
No image editing. Source copy checksum equals original; see source.sha256.
Low performance (four slow >120ms rendered frames), WebGL loss, image failure,
hidden document, offscreen host, reduced-motion preference all fall back to original.
Current prototype requires card container aspect/object-fit match original, as demo.
