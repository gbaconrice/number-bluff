# ナンバーブラフ / Number Bluff

GRAVITYの音声ルームから利用することを想定した、数字推理・ブラフのWebカードゲーム。

## 開発方針
- ゲーム本体はこのリポジトリで開発・テストし、Web公開する。
- GRAVITY側は外部ゲームを読み込む小さなローダーにする想定。
- **GitHub Pagesは静的ファイルを配信するだけ**。参加者の共有ルーム、非公開カード、BOTの確定処理には別途リアルタイム通信基盤と権威あるゲーム状態管理が必要。
- GRAVITYからの外部埋め込み、マイクとの併用、iframe制約は実機で確認する。
- 初期段階はローカル1人対BOTの動作確認版。外部公開しただけでマルチプレイが成立するとは表示しない。

## 目標仕様
- 人間とBOTを合わせて2〜8人。BOTの上限を厳守。
- 自分のカードは非公開、ほかのプレイヤーのカードは見える。
- 宣言（0以上の整数で前より大きい数）と「グラビティ！」による判定。
- ライフ3、脱落、再戦、同じルームでの通算勝利数。
- 数字32枚＋特殊4枚の36枚デッキ。
- 遊び方・カード図鑑とモバイル最優先のUI。
- ルームIDでの作成・参加。公開ルーム一覧は不要。

## 開発と公開
- 現在の実装は通常数字24枚（0・1・2・3・5・10が各4枚）、1人対BOT。上の36枚・共有ルームは今後の目標で、実装済みの機能ではない。
- `engine.js` はゲームの状態遷移、`scheduler.js` はBOTの予約処理、`app.js` は画面の操作を担当する。再戦したあとに前のBOT操作が残らないよう、予約の取り消しと世代確認を行う。
- Node.js 22以上で `npm test` を実行する。ブラウザ検証はPRの検証ワークフローで行う。自動検証と実機のGRAVITY連携の確認は分けて記録する。
- `index.html` は静的ホストで配信できる初期版。
- GitHubリポジトリの **Settings → Pages → Build and deployment** で `Deploy from a branch` / `main` / `/ (root)` を選択すれば、権限と公開設定が対応する場合にPagesで配信できる。
- 想定URL: `https://tanabe0422.github.io/number-bluff/`（Pagesを有効化するまで未公開）。
- GRAVITYローダーには検証済みの公開URLだけを指定する。

## 注意
原作ゲームのロゴやカードイラストは利用せず、独自の名称・意匠とする。
